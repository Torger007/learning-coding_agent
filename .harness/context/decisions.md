# 架构决策记录 (ADR)

## ADR-001: 三层规则框架

**状态**: 已接受
**日期**: 2026-04-24
**决策**: 采用 L1(核心约束) + L2(领域规则) + L3(指南示例) 的分层框架

**上下文**:
- 旧规则文件过于臃肿（1600+行），挤占 AI 上下文
- 需要区分"必须遵守"和"参考指南"

**决策**:
- L1 `AGENTS.md`: ≤10条，始终加载
- L2 `rules/`: 按需读取
- L3 `guides/`: 手动参考

**后果**:
- AI 上下文更轻量
- 规则维护更清晰
- 需要训练团队按需引用 L2/L3
