# /plan

为预计超过 30 分钟或涉及 >3 个文件的任务生成结构化计划。

## 输出格式

```markdown
## 任务: [标题]

### 影响分析
- 修改文件: [列表]
- 风险点: [列表]
- 需确认点: [列表]

### 执行步骤
1. [步骤1] — 预计 [X] 分钟
2. [步骤2] — 预计 [X] 分钟
3. [步骤3] — 预计 [X] 分钟

### 验证方法
- [ ] 单元测试通过
- [ ] 手动功能验证
- [ ] 安全检查通过

### 回滚方案
如需回滚: `git revert [commit]` 或 [具体步骤]
```

## 规则

- 每个子任务不超过 200 行变更
- 明确标注依赖关系（步骤 N 依赖步骤 M）
- 标记所有需要人工确认的点
