# /review

审查当前工作区的变更（staged + unstaged）。

## 检查清单

### 代码质量
- [ ] 类型注解完整
- [ ] 公共函数有文档字符串
- [ ] 无重复代码
- [ ] 命名清晰

### 安全
- [ ] 无硬编码敏感信息
- [ ] 用户输入有验证
- [ ] 无危险函数调用（eval, exec 等）

### 测试
- [ ] 核心逻辑有测试覆盖
- [ ] 测试通过

### 架构
- [ ] 符合项目目录结构
- [ ] 模块边界清晰
- [ ] 无循环依赖

## 输出

```markdown

### 变更摘要
- 修改文件: N 个
- 新增文件: N 个
- 删除文件: N 个

| 严重度 | 文件 | 问题 | 建议 |
|--------|------|------|------|
| 🔴 High | ... | ... | ... |
| 🟡 Med | ... | ... | ... |
| 🟢 Low | ... | ... | ... |

### 通过项
- [x] ...

### 建议
...
```
